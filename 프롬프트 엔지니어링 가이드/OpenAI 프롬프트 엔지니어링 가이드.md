# **📘 OpenAI 프롬프트 엔지니어링 가이드 (실전 예시 포함)**

## **1\. 최신 모델 사용하기**

* **원칙**: 최신 모델일수록 더 정확하고 똑똑합니다.

* **비유**: 오래된 휴대폰보다 최신 스마트폰이 더 빠르고 기능이 좋은 것처럼, AI도 최신 버전이 더 나은 답을 줍니다.

**예시**  
 ❌ 구버전 사용: “GPT-3.5에게 블로그 글을 써달라.”  
 ✅ 최신 모델 사용: “GPT-5에게 블로그 글을 써달라.” → 더 매끄럽고 정확한 결과가 나옴

---

## **2\. 지시는 프롬프트 맨 앞에 배치**

* **원칙**: AI에게 내릴 ‘명령’은 항상 맨 앞에 두세요.

* **비유**: 친구에게 부탁할 때 “마트 가서 우유 사와”를 제일 먼저 말하는 것과 같아요.

**예시**  
 ❌ “오늘은 날씨가 좋다. 이 내용을 3문장으로 요약해줘.”  
 ✅ “3문장으로 요약해줘. \#\#\# 오늘은 날씨가 좋다.”

---

## **3\. 요구사항은 구체적으로**

* **원칙**: 애매한 말보다 수치나 조건을 명확히 써야 합니다.

* **비유**: “짧게”라고 하면 사람마다 다르지만, “3문장으로”라고 하면 누구나 똑같이 이해합니다.

**예시**  
 ❌ “시를 짧게 써줘.”  
 ✅ “봄을 주제로, 3행, 밝고 따뜻한 분위기의 시를 써줘.”

---

## **4\. 원하는 출력 형식 제시**

* **원칙**: AI에게 결과물이 어떤 모습이어야 하는지 직접 보여주세요.

* **비유**: 숙제할 때 선생님이 모범 답안을 보여주는 것과 같아요.

**예시**  
 “아래 형식으로 출력해줘:

* 이름:

* 나이:

* 직업:”

👉 그러면 AI가 같은 형식을 그대로 따라냅니다.

---

## **5\. 단계별 접근 (Zero-shot → Few-shot → Fine-tuning)**

* **원칙**: 간단한 프롬프트로 시작하고, 필요하면 예시를 추가하고, 최종적으로는 모델을 훈련하세요.

* **비유**: 요리 배울 때 처음엔 설명만 듣다가, 안 되면 시범을 보고, 그래도 안 되면 직접 배워서 연습하는 것과 같아요.

**예시**  
 1단계 (Zero-shot):  
 “고양이에 대한 시를 써줘.”

2단계 (Few-shot, 예시 제공):  
 “아래 예시처럼 고양이에 대한 시를 써줘.  
 예시: ‘하얀 고양이 / 창가에서 졸고 있네 / 햇살은 따뜻하다.’”

3단계 (Fine-tuning):  
 → 고양이에 대한 시를 계속 잘 쓰도록 모델 자체를 훈련시킴

---

## **6\. 부정 지시 대신 올바른 지시**

* **원칙**: “하지 마”만 쓰면 AI는 멈춰버립니다. 대신 **해야 할 행동**을 함께 알려주어야 합니다.

* **비유**: 아이에게 “길에서 뛰지 마” 대신 “인도에서 걸어가”라고 말하는 게 더 효과적인 것과 같아요.

**예시**  
 ❌ “고객에게 비밀번호 묻지 마.”  
 ✅ “비밀번호는 절대 묻지 말고, 대신 고객센터([www.example.com/help](http://www.example.com/help)) 링크를 안내해줘.”

---

## **7\. 코드 작성 시 힌트 주기**

* **원칙**: 원하는 언어나 구조를 미리 넣어주면 AI가 그 형식에 맞춰 답합니다.

* **비유**: 글쓰기 할 때 “시작은 ‘옛날 옛적에’로 해”라고 하면 이야기가 자연스럽게 이어지죠.

**예시**

* Python 코드가 필요할 때:  
   “아래처럼 시작해줘:

import  
\`\`\`”  

\- SQL 쿼리가 필요할 때:    
“SELECT로 시작하는 쿼리를 작성해줘.”  

\---

\#\# 8\. 단순하고 명확하게  
\- 원칙: 복잡한 말보다는 짧고 직관적인 말이 효과적입니다.    
\- 비유: “조금만”이라고 하면 애매하지만, “한 스푼”이라고 하면 정확합니다.  

예시  
❌ “짧게 설명해줘.”    
✅ “3문장으로 요약해줘.”  

❌ “조금 길게 설명해줘.”    
✅ “200자 정도로 설명해줘.”
